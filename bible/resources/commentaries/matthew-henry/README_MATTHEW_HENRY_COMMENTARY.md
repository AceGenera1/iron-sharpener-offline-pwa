# Matthew Henry Commentary Resource Package

Install by copying the `bible/` folder into the Iron Sharpener project root.

Expected destination:

```text
bible/resources/commentaries/matthew-henry/
```

Generated from the uploaded Matthew Henry Concise Bible Commentary PDF. Only the main commentary text was converted; cover/front-matter metadata was not used as resource content.

Parsed commentary headings: 3580
Verse keys written: 25939
Book JSON files: 66

Important UI note: range-based notes are mapped to every verse in that range. Add/keep the commentary dedupe patch in Iron Sharpener so a five-verse passage does not display the same range note multiple times.
