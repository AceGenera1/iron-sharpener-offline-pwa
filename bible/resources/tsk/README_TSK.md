# Iron Sharpener Treasury of Scripture Knowledge Resource

Source: public-domain Treasury of Scripture Knowledge PDF supplied for Restored Daily Ministries / Iron Sharpener, supported by CrossWire's public-domain TSK module listing.

Install folder:
`bible/resources/tsk/`

Generated files: 66 book JSON files plus `_AUDIT_TSK.csv`.

Audit summary:
- Verse keys with at least one mapped reference: 12,781 / 31,103
- Extracted normalized reference buttons: 302,800

Notes:
- This resource is built for Iron Sharpener's internal cross-reference panel.
- TSK includes many topical subheadings and explanatory notes; this package extracts normalized Scripture references only for clickable navigation.
- The supplied PDF is OCR-based, so the package keeps only references that can be normalized to valid 66-book Scripture references.
